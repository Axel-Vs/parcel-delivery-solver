### Added

- **K-Medoids Clustering (PAM Algorithm)**: Intelligent geographical vendor grouping
  - Uses travel time distance matrix (real road distances, not Euclidean)
  - Creates 12+ clusters for 58 vendors (target: 3 vendors per cluster)
  - K-Medoids++ initialization: probabilistic seeding for better convergence
  - Identifies extreme outliers (>2σ from mean) for dedicated routes
  - Provides feasible initial solution for ALNS optimization
  
- **Route Statistics with Time**: Display driving hours in route cards
  - Added TIME (hrs) metric showing total driving time per route
  - Calculated from segment durations (travel + service time)
  - Displayed alongside: Vendors, Distance (km), Cargo (kg), Volume (m³)
  
- **Selective Route Fixing**: Intelligent constraint violation handling
  - Parses violation messages to identify specific routes
  - Splits ONLY violated routes into single-vendor routes
  - Keeps all feasible routes intact (preserves optimization quality)
  - Expected ~30% vehicle reduction vs trivial fallback
  
- **Route Merging Optimization**: Reduce vehicle count while respecting constraints
  - Runs every 250 ALNS iterations + final aggressive pass
  - Tests all route pairs for feasibility (capacity + max_driving)
  - Keeps merge only if constraints satisfied
  
- **Improved Clustering Parameters**:
  - Changed target from `len(vendors) // 4` to `len(vendors) // 3` (more clusters)
  - Removed artificial max 12 cluster limit (now unlimited)
  - Changed outlier threshold from 1.8σ to 2.0σ (fewer extreme outliers)
